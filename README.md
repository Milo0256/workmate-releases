# 워크메이트 설치 파일

소규모 회사용 AI 업무비서 **워크메이트**의 설치 파일과 자동 업데이트 정보만 올라가는 곳입니다. 소스 코드는 없습니다.

## 설치

1. 오른쪽 **Releases**에서 가장 최신 버전의 `WorkMate-Personal-<버전>-setup.exe`를 내려받습니다.
   - 바로 받기: [최신 설치 파일 목록](https://github.com/Milo0256/workmate-releases/releases/latest)
2. 내려받은 파일을 실행합니다. 관리자 권한 없이 설치되고, 시작 메뉴와 바탕화면에 바로가기가 생깁니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
3. 처음 켜면 **라이선스 키**를 넣습니다(판매자에게 받은 키).

## 업데이트

설치한 뒤에는 앱이 이곳에서 새 버전을 알아서 받아 둡니다. 메인 창 위쪽 띠에서 **다시 시작해서 설치**를 누르거나, 트레이에서 종료할 때 설치됩니다.

업데이트 정보(`latest.json`)는 판매자 배포 키로 서명되어 있고, 받은 설치 파일은 크기와 SHA-256을 확인한 뒤에만 설치됩니다.
